# 🛒 CartLens — Shop Smarter, Not Harder 🚀

**Stop tab-hopping and start deciding.** 

Ever spent 2 hours opening 15 different tabs just to figure out which phone has the better battery or which laptop actually fits your budget? Yeah, we've all been there. **CartLens** fixes that. 

It's your AI-powered shopping sidekick that rips the technical specs out of any product page and throws them into a high-power comparison grid. No more manual scrolling, no more "wait, which one had the 5000mAh battery again?"

---

## ✨ The Magic (Features)

- **⚡ Instant Extraction**: One click and CartLens scrapes the deep technical data, pricing, and reviews. No matter how messy the website is.
- **📊 Power Specs Grid**: A side-by-side "Battle Mode" for your products. Compare specs instantly and see who actually wins.
- **🤖 AI Comparison Chat**: Got a specific question? Just ask. *"Which of these is better for 4K video editing?"* or *"Which one is the best value for money?"* The AI knows the specs and gives you the answer.
- **🚀 Quick Add**: See something you like? Hit "Quick Add" and it's in your comparison list immediately.
- **🔒 Lean & Mean**: Optimized workflow to keep it fast, lightweight, and accurate.

---

## 🛠️ Tech Stack (The Engine)

We didn't just build this; we engineered it for speed.

- **Frontend**: React + TypeScript + Tailwind CSS (for that clean, modern vibe) + Vite.
- **Backend**: FastAPI (Python) + LangGraph + LangChain.
- **Brain**: Powered by Groq LLM for near-instant response times.
- **Storage**: SQLite for session management.

## 📦 Installation (Get it Running!)

Since this is a community-driven project, you can install it via **Developer Mode**:

1. **Download**: Grab the latest `dist.zip` from the [Releases](#) section.
2. **Unzip**: Extract the folder anywhere on your laptop.
3. **Chrome Setup**:
   - Open Chrome and go to `chrome://extensions/`
   - Toggle **Developer Mode** (top right corner) 🛠️
   - Click **Load unpacked** 📂
   - Select the extracted `dist` folder.
4. **Start Shopping**: Pin the extension and start adding products!
